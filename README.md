# Installation

## Dependencies

For run the project you need to install:
JDK 25 at:
```https://www.oracle.com/java/technologies/downloads/```

and Docker.

## Configuration

You need to create a .env file, you can do it copying the .env.example
after, you run the follow command:
```shell
docker compose up
```
for stop the container you can run:
```shell
docker compose down
```
